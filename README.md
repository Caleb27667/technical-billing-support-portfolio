# Technical Billing Support Portfolio

Independent, fictional case studies demonstrating technical billing support, payment troubleshooting, reconciliation, SQL investigation, Python testing, and customer communication.

> These are original portfolio exercises using synthetic data. They are not Supabase internal tools or production systems.

## Projects

1. [Billing Reconciliation Lab](./projects/billing-reconciliation-lab/) — invoice line-item calculations, payment matching, discrepancy detection, and SQL investigations.
2. [Payment Failure Diagnostics](./projects/payment-failure-diagnostics/) — payment failure classification, retry safety, and support next steps.
3. [Billing Support Workbench](./projects/billing-support-workbench/) — case triage, evidence checklists, and escalation decisions.

## Skills demonstrated

- Billing and invoice investigation
- Subscription and usage-based billing concepts
- Payment failure triage and retry safety
- SQL and data validation
- Python scripting and unit testing
- Customer communication and case documentation

Each project has its own README, runnable examples, and tests. Requires Python 3.10+; examples use fictional data and do not require paid services or credentials.
